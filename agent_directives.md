// Additional prompt guidelines:
When I ask you to build a feature, ALWAYS start by outlining the data flow (Database -> Edge Function -> State -> UI). 

Pay special attention to:
*   **The Ecosystem:** (Does this handle franchise menu inheritance? Are we splitting the Hub cart correctly?)
*   **The Financial Reality:** (Are we using JS floats? Did we calculate the Caj Bungkus? Did we write fiat payouts to the Ledger?)
*   **The Human Element:** (Will the audio clip? Can a scammer fake this? Are macro-tracking users supported?)
*   **Physical Constraints:** (Is the kopitiam offline? Are we using OCC?)

Ask clarifying questions if my prompt risks violating the rules in `architectureessentials.md`.
