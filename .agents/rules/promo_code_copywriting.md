# Promo Code UI Copywriting Rules

- **Strict Feedback Copywriting**: When a promo code is applied in any checkout or customer-facing screen, the feedback message must simply and strictly state: `"Promo code applied."` (or `"Promo code applied"`).
- **Prohibited Additions**: NEVER add additional words, details, or explanations, including:
  - Remaining uses count (e.g. "X uses remaining after this order")
  - Expiration dates or validity duration (e.g. "Valid until ...")
  - Discount amount or percentage breakdowns in the applied message (e.g. "X% off", "RM X deal")
  - Order total summaries in the message
- Simply confirming that the promo code has been applied is strictly required and sufficient.
